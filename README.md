# PDF Reader 0.6.0

一个面向 Windows 的极简 PDF 阅读器。工具居中放在顶部，页码和缩放在底部，页面、AI、批注和终端侧栏按需展开。阅读、编辑、批注、手写签名和中英 OCR 均在本地完成。

0.6.0 的阅读对话默认附加三层内容：整份 PDF 背景、当前页截图、有选区时的选中文字。首次提问时一起发送，后续提问继续携带全文背景；翻页或编辑后更新对应内容。输入框 ＋ 可调整范围，AI 设置提供全文文字兼容模式。聊天、草稿和文档背景写入本机加密 SQLite，支持恢复、历史、导出和删除。底部标签、居中工具栏、Markdown、原样式编辑、自动 OCR 和高 DPI 矢量图标继续保留。完整改动见 `CHANGELOG.md`。

## 运行

**免安装版：**解压完整的 `PDFReader-Windows-x64.zip`，打开 `PDFReader` 文件夹，双击 `PDF Reader.exe`。请保留旁边的 `_internal` 文件夹。PDF 引擎、Qt 运行库、中英文 OCR 模型均已附带，无需 Python、Tesseract 安装或联网下载。

**系统：**Windows 10/11 x64。启动后点击“试读示例”，即可体验包含文字页、扫描页和签名区域的示例文档。打开对话框可多选文件，也可一次拖入多份 PDF；命令行支持多个路径，如 `& '.\PDF Reader.exe' 'D:\Documents\a.pdf' 'D:\Documents\b.pdf'`。

**源码：**Python 3.12，执行 `python -m pip install -r requirements.txt`，然后 `python main.py`。依赖安装需要联网，安装后的阅读、编辑和 OCR 不需要联网。`build.ps1` 可运行测试并重新打包。

## 编辑与签名的范围

- 原样式编辑读取字体、字号、颜色、透明度和基线位置，保留混合样式；新文字继承附近文字的样式。优先复用嵌入字体，必要时使用本机已安装的同一字型。原字体不可用或缺少新增字形时会提示，保留原文；你可明确取消“保留原文样式”并选择替代字体、字号和颜色。
- 点击编辑默认选中文字行，可利用右侧空白，遇到相邻文字、图像或边界时停止扩展；多行内容可用拖框编辑。文字放不下时提示调整，不自动缩小字号，也不重排选框以外的段落。任意角度变换、特殊描边等复杂样式可能无法原样编辑。
- 扫描页的原字在图像中，OCR 不提供其真实字体和颜色。编辑这类文字会提示使用扫描件覆写，并显示替代字体设置；覆写会清除选框内图像背景，以白底重写，不进行背景修复。
- 签名是可见手写笔迹，**不是证书数字签名**，不提供身份认证、签名验证、时间戳或防篡改承诺。修改含证书签名的 PDF 可能影响原签名。
- OCR 适合印刷体中英文。手写、复杂表格、低清晰度、多栏页面的结果需要复核。自动检测跳过已有文字层的页；混合图文页的局部 OCR、方向自动纠正和校对界面尚未实现。
- 当前没有 PDF/A 校验、专业印前处理、测量、XFA、Word/Excel 格式转换、全文排版重建、证书签章或 Acrobat 插件兼容层。
- 终端支持常用 ANSI/VT 命令行交互；复杂全屏 TUI 的兼容性有限。停止终端会结束它创建的进程树。终端是否联网取决于你运行的程序。
- 原始文档不会自动保存或上传。尚未实现崩溃恢复、重启恢复标签、超大文档后台全文索引。超大页面的显示分辨率会受像素上限约束。

## 配置 AI

1. 点击顶部星形图标展开 AI 侧栏，点击右上角 **… → AI 连接设置**。
2. 填写服务提供方的 API Base URL、模型名称和 API Key。地址可为 `https://你的服务/v1` 或完整的 `/chat/completions` 地址。本机服务可用 `http://127.0.0.1:端口/v1`。
3. 勾选允许向该服务发送消息。远程服务使用 HTTPS；应用不自动跟随 HTTP 重定向。
4. 打开 PDF 后，新对话默认 **自动 · 全文 + 当前页 + 选区**。首次提问同时发送整份 PDF、当前页截图，有选区时再附加完整选中文字。打开文档、翻页和划词只更新待发送内容，不请求 AI。输入框 **＋** 可改为不附加文档信息、仅选中文字、仅当前页截图；点标签预览全文信息、当前页和选区，× 移除。
5. AI 设置中的 **文档背景** 默认 **PDF 文件**，以内嵌文件消息发送，遵循 [Chat Completions PDF 输入格式](https://developers.openai.com/api/docs/guides/file-inputs)。需要服务和模型同时支持 PDF 输入。PDF 是当前文档的内存快照，包含未保存修改及已完成的 OCR；不会改写原文件。已打开的加密 PDF 在内存中解密后发送，不发送打开密码；内容提取权限受限时会阻止全文附件。
6. 若服务不支持 PDF 文件，改用 **全文文字**。此模式提取所有页的文字并标注页码，不包含其他页面的图表图像；缺少文字层的页明确标记，全部无文字时提示等待 OCR 或改用 PDF。截图仍需服务和模型支持图片输入；纯文字模型可通过 ＋ 选择仅选中文字。截图只渲染当前 PDF 整页及批注，不含桌面或其他窗口，长边不超过约 1600 像素。
7. Chat Completions 请求没有持久的服务端会话，本应用在自动模式下**每次发送全文背景**，另加当轮截图、选区和最近最多四组完整问答（历史文字上限 24,000 字符）。全文独立于历史窗口，不因对话变长而被移除；编辑、OCR、撤销或切换文件后会刷新。每轮带全文可能增加服务用量。旧的单页截图不会重发，当前页截图每轮重新生成。
8. 本地限制：PDF 快照小于 50 MB；全文文字最多 200,000 字符；选区最多 12,000 字符。超过限制明确提示，保留问题，不悄悄截断或降级。服务还可能有更小的文件、令牌或上下文限制，可缩小附件范围后重试。
9. “不附加文档信息”指本轮不添加全文、新截图或新选区，已有会话文字仍参与上下文。要开始独立话题，使用 **… → 新对话** 后选择不附加文档信息。没有打开 PDF 时默认独立聊天。
10. AI 回复显示 Markdown，不执行命令、不修改 PDF。Markdown 内的图片、远程资源和原始 HTML 被禁用；点击网页链接仅提供复制选项。**… → 复制最近回答** 保留原始 Markdown。

本软件不提供 AI 账户、额度或大模型权重。真实服务需要你自己的配置。API 密钥默认仅保存在内存；选择“记住密钥”后使用 Windows DPAPI 按当前用户加密。密钥只用于向配置的服务鉴权，不写入聊天数据库；应用没有开发者中转服务。联网请求中的问题、历史和所选附件会交给服务提供方，其保存、训练或日志政策取决于该服务。此处的本机加密不代表服务端保密。

## 保存聊天记录

从 0.5.0 起，记录自动保存，无需另装数据库、注册账号或手动保存聊天。

- 数据库位于 `%LOCALAPPDATA%\PDFReader\chat-history.sqlite3`。正文、草稿、附件、全文背景、标题及文件路径经 Windows 当前用户加密后才写入 SQLite；时间、记录 ID、文档路径和背景内容摘要作为索引。运行时可能同时存在 `-wal`、`-shm` 文件。
- 全文背景单独加密保存，相同内容在多个会话中复用；输入草稿和流式回复不会反复写入整份 PDF。每段会话保留最近使用的文档背景，旧轮次保留当时的页面截图、选区和背景说明；不归档每次修改的完整 PDF。删除最后一个引用后回收该背景数据。
- 草稿停止输入约 0.7 秒后保存；发送、回复完成、切换文档和退出时保存。流式回复途中也会保存部分内容；意外中断后保留已落盘部分。PDF 原文件仍需要你点击保存。
- 同一路径的 PDF 重新打开时恢复最近对话；两份 PDF 不共用上下文。切换标签会停止正在生成的回答。另存为复制当前对话到新路径，原路径记录保留。
- 右上角 **时钟** 打开历史，按标题搜索；选择“所有本机记录”查看其他 PDF 的聊天。原文件被移动或尚未保存的记录可作为归档查看、导出和删除。
- **… → 新对话** 保留旧历史。**… → 导出 Markdown** 导出普通、未加密的 `.md` 文件，含正文、所选文字与草稿；截图和全文背景不嵌入导出文件。打开原 PDF 的历史对话后，点消息中的附件标签可预览原截图和选区。
- **… → 删除当前对话** 需确认。若数据库不可写，侧栏会显示保存失败，退出时提醒；此时可先导出记录。两个应用窗口同时更改同一对话时保留为两条记录，避免静默覆盖。
- 加密记录绑定当前 Windows 用户环境；跨电脑或更换账户前可导出 Markdown。备份数据库应先退出应用，再复制数据库文件。旧版仅在内存中的会话不会被新版自动找回。
- 0.6.0 自动迁移 0.5.0 数据库并保留原会话。迁移后请用 0.6.0 或更新版本查看聊天；0.5.0 无法读取新结构。旧会话首次进入新版会采用新的自动附加默认值，之后会记住你在 ＋ 中的选择。

配置与插件存放在 `%LOCALAPPDATA%\PDFReader`。从旧版升级时自动读取原 `SlatePDF` 目录中的设置和插件，原文件保持原样。OCR 临时快照也在配置目录，正常结束或取消后删除；程序异常退出时可能留下临时文件。加密 PDF 的 OCR 临时快照为解密后的本地数据。

## 插件

本版本使用清单式扩展，不加载第三方 Python 代码。`plugins` 目录提供示例。修改命令或模型名称，再通过顶部菜单中的“插件 → 导入插件清单”导入。

AI 清单示例：

```json
{"name":"我的模型","kind":"ai","endpoint":"https://your-provider.example/v1","model":"model-name"}
```

终端清单示例：

```json
{"name":"本地 AI","kind":"terminal","command":["ollama","run","your-installed-model"]}
```

AI 预设在“插件 → AI 服务预设”中选择；终端预设在终端下拉框中选择后点击三角形运行按钮。清单本身不会自动执行命令，也不会自动下载 CLI 或模型。终端执行的是本机程序，具有当前用户的文件访问权限。

## 结构与验证

`pdfreader/engine.py` 封装 PDF 操作与历史；`documents.py` 管理独立文档会话与标签；`text_edit.py` 负责原样式编辑；`text_selection.py` 负责文字选择；`viewer.py` 管理延迟渲染与坐标换算；`layout.py`、`icons.py`、`style.py` 组织界面；`ocr.py` 是独立识别进程；`ai.py` 是唯一 HTTP 客户端；`ai_context.py` 准备全文快照和兼容文字背景；`panels.py`、`chat_markdown.py` 和 `chat_store.py` 分别负责聊天交互、原生 Markdown 和加密 SQLite；`terminal.py` 使用原生 ConPTY；`app.py` 连接操作流程。

```powershell
python -m pytest tests -q
python main.py --smoke-test .\smoke-output
```

自动化测试覆盖真实鼠标划词和复制、跨页选区、旋转、选择后高亮、实际 PDF 重开、文字移除、批注/签名、页面操作、加密、保存失败回滚、OCR 像素一致性、搜索取消、缩放锚点、终端旧事件隔离、配置迁移与 AI 流式响应。独立 smoke 测试包含实际鼠标划词、中英 OCR 后划词、保存重开、截图和终端命令回显。测试记录见 `VALIDATION.md`。

第三方真实 AI 服务未使用私人账户验证。物理打印机、不同 Windows 版本和所有 PDF 变体尚未逐项验证。
